# ゲーム設計書：ワンオペ！食堂は戦場に！？

「デイヴ・ザ・ダイバー」の寿司屋パートをベースにした定食屋ゲーム。
**営業中の忙しさ**と、**営業前後の経営の楽しさ**を両立させることを最重要とする。

- 2Dドット絵 / 斜め見下ろし / 横向き画面
- iPhone・iPadのタッチ操作が前提。開発・確認はPCで行う（マウスで操作できること）

---

## 1. 基本サイクル（1日の流れ）
1. **営業準備**：食材の確認、メニュー設定、仕込み（作っておく個数の設定）
2. **営業開始**：お客さんが来店し、注文する
3. **調理・配膳**：注文に応じて料理を作り、提供する
4. **営業終了**：売上・経費・評価を確認する
5. **お店の強化**：新メニュー、設備、従業員を強化する → 次の日の営業へ

## 2. 営業パート
### 2-1. お客さん
| 客層 | 特徴 |
|---|---|
| サラリーマン | 昼休みに来店。待ち時間に厳しい |
| 学生 | 安いメニューを好む |
| 家族連れ | 複数人で来店。注文数が多い |
| 常連客 | お店のファン。多少待ってくれる |
| グルメ客 | 料理の品質を重視する |
| 大食い客 | ご飯大盛りや追加注文が多い |
| 急いでいる客 | 提供が遅いと帰ってしまう |

パラメータ：注文するまでの時間、料理を待てる時間、好きな料理、予算、満足度、食事にかかる時間、支払金額、口コミへの影響

行動フロー：来店 → 着席（空いている席を探す）→ 注文 → 待機（長いと不満が増える）→ 食事 → 会計 → 退店（満足度に応じて評判が変わる）

### 2-2. 注文
- 着席すると注文が発生する。**最初は自動注文**（プレイヤーの操作を調理と配膳に集中させる）
- 将来の案：手動注文（客をタップして注文を受ける）
- 注文票に表示する内容：料理名、内容（ご飯・味噌汁・唐揚げ・漬物など）、価格、テーブル番号、待ち時間、満足度の状態

### 2-3. 調理
- 料理ごとに必要な食材を決めておく（例：唐揚げ定食 = 鶏肉・キャベツ・米）
- 営業準備で、料理ごとに作っておく個数を決められる
- 営業中は、料理を選ぶと店主が時間をかけて作ってくれる（ワンクリック調理）。食材が足りないと作れない

### 2-4. 配膳
- 料理をタップして持つ → 注文したお客さんをタップして提供する
- 注文と料理が一致すれば成功、違う料理だとミス
- 提供までの時間で評価が決まる：早い＝大満足 / 普通＝満足 / 遅い＝やや不満 / 非常に遅い＝怒って帰ることがある

### 2-5. 営業中のトラブル（慣れてきた頃に追加）
注文の集中、待ち時間の超過、テーブルの片付け忘れ、従業員の疲労

## 3. 定食屋ならではの機能
### ご飯の量
| 種類 | 価格 | 食材の消費 |
|---|---|---|
| 小盛り | 基本価格 | 少ない |
| 普通 | 基本価格 | 普通 |
| 大盛り | +100円 | 多い |
| 特盛り | +200円 | 非常に多い |

### トッピング・追加注文（例：唐揚げ定食）
卵焼き +150円 / ポテトサラダ +150円 / コロッケ +200円 / 唐揚げ追加 +250円 / 味噌汁を豚汁に変更 +150円

## 4. 経営・成長
### 4-1. 営業結果
売上（料理売上）、食材原価、人件費、その他経費、利益、来客数、評価、完了した注文の数

### 4-2. 評判・人気度
無名店 → 知る人ぞ知る店 → 人気店 → 有名店（人気が上がるほど来店客が増える）
人気度に影響するもの：料理の品質、提供速度、接客、価格設定、メニューの豊富さ、店内の清潔さ

### 4-3. 従業員（ランク3で解放）
| 職種 | 仕事内容 |
|---|---|
| ホールスタッフ | 注文受付・料理提供 |
| 調理スタッフ | 調理 |
| 洗い場スタッフ | 食器の片付け |
| 店長補佐 | 店舗全体の業務補助 |

能力値：調理速度、接客速度、作業効率、スタミナ、給料。最初はプレイヤー1人で運営する。

### 4-4. 設備
炊飯器（ご飯の準備時間を短縮）、フライヤー（揚げ物の調理時間を短縮）、コンロ（焼き物・炒め物の調理時間を短縮）、食器棚（提供準備の効率を上げる）、テーブル（最大来店客数を増やす）、椅子（客席数を増やす）

### 4-5. 店舗ランク
| ランク | 解放内容 |
|---|---|
| 1 | 基本の定食 |
| 2 | 新しい料理・トッピング |
| 3 | 従業員の雇用 |
| 4 | 厨房設備の拡張 |
| 5 | 新しい客層 |
| 6 | 店舗の拡張 |
| 7 | 高級料理・特別メニュー |

## 5. 画面
- **営業画面**：店内マップ、お客さん、テーブル・椅子、厨房・調理器具、完成した料理、**注文状況（画面の端に常に表示）**、営業の残り時間、所持金、管理ボタン
- **営業準備画面**：今日のメニュー、販売価格、食材の仕入れ、在庫、従業員の配置、設備、料理の用意（個数）、営業開始
- **メニュー開発画面**：料理一覧、必要な食材、調理時間、原価、販売価格、利益、人気度、開発の条件
- **経営管理画面**：所持金、売上・利益の履歴、来客数、人気度、従業員、設備、ランク
