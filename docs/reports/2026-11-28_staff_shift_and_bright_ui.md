## 1. スタッフの出勤（シフト）
- 準備③に「今日のスタッフ」の欄を作りました（置き場の右側）
- 雇っている人ごとに、次のものを出します
  - 機嫌の顔のマーク（◎○△×）と色
  - 名前と機嫌の名前（ごきげん・ふつう・疲れ気味・限界）
  - 日給、または出られない理由（「休み（定休：金・土）」「休み（急用）」）
  - 「出勤／休み」のボタン
- 出勤にした人だけが営業画面で働き、日給もその人の分だけかかります
- 出勤は、はじめから前回と同じです（前回休みにした人は休み、雇ったばかりの人は出勤）
- 出られない日はボタンを押せません
- 毎週の休みと急な休みの確率は `data/staff/*.tres`（`days_off`・`absence_rate`）にあります。急な休みは「次の日へ」で翌日の分を決めます
- 強化画面の候補の行に「定休：月」を出し、長押しの詳細には次のものを出します
  - 速さ・日給・毎週の休み
  - 急な休みの多さ（約○%）
  - 今の機嫌（雇っている人だけ）
- 準備③は、置き場とスタッフの欄を左右に並べました。どちらも、入りきらなければ指でなぞってスクロールします

## 2. 満足度と、辞めること
- 強化画面の「やめてもらう」をなくしました
- 計算は `scripts/staff_mood.gd`、数値はすべて `game_config` の「従業員の満足度」にあります
- 満足度が35以下になると、準備③に注意を出します（例：「佐藤さん：最近疲れているようです（連勤が続いています）」）
- 20未満の日は、営業結果で確率で辞めます。結果画面に「佐藤さんが辞めました（連勤が続いたため）」と、いちばん大きな理由を出します
- 辞めた人は候補に戻り、雇い直すと「ふつう」から始まります

### 自分で決めた数値（仮）

## 5. ボットでの結果（365日・高速モード・seed 1〜3）
- ボットのシフトの決め方：
  - 出られない日は休み
  - 連勤が4日目に届く前の日（3日つづけて出勤したあと）は休ませる
  - 機嫌が「疲れ気味」に近い人も休ませる

| ボット | 辞めた回数（3年分） | 出勤した人数の平均（1日） | ランク2 / 3 / 4 |
|---|---|---|---|
| うまい人 | **0回** | 1.4人 | 4 / 8 / 15〜16日目 |
| ふつう | **0回** | 1.6人 | 5〜7 / 11〜13 / 22〜24日目 |
| 下手 | **0回** | 1.5人 | 58〜77 / 132〜137日目 / 届かない |

- 比べる用に、休ませないボット（`--no-rest`）も回しました（出られる日は毎日出勤）

| ボット | 辞めた回数（3年分）と理由 |
|---|---|
| うまい人 | 0回 |
| ふつう | 3回（連勤 2回、忙しすぎる日 1回） |
| 下手 | 6回（すべて連勤） |

- ふつうに休ませていれば、ほとんど辞めません。休ませないと、連勤で辞めることがあります
- 下手なボットのランクアップは、前回（ランク2が約50日目、ランク3が約108日目）より遅くなりました。スタッフを休ませる日ができて、手伝ってもらえる日が減ったためです

## 既知の問題・気になる点
- **きちんと休ませていると、満足度はほぼずっと高いまま（平均98）**です。落ち着いた日の +2 が多めに効いているためで、今の数値だと、辞めるのは休ませない遊び方のときだけです。もう少し気をつかわせたい場合は、落ち着いた日の上がり方を小さくするなどで調整できます（すべて game_config）
- **下手なボットのランクアップが遅くなりました**（ランク3が約135日目）。前回の目安（ランク3が200日目前後）よりはまだ早いです
- スタッフの体や家具など、営業画面の「絵がないときの代用の図形」の色は .tscn に残っています（customer.tscn・hall_staff.tscn など）。ドット絵に差し替えるまでの仮の図形なので、そのままにしました
- 準備③（16:9）では、左側の「今日の仕込み：…」の行が置き場の下にあり、少しスクロールしないと見えないことがあります
- 急な休みは「次の日へ」を押したときに決めます。セーブには入るので、アプリを開き直しても変わりません
