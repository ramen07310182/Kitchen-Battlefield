## 変更点
- **CLAUDE.md に「確認の段階」を追加しました**
  - 軽い確認・しっかり確認・バランス確認の3段階と、報告書は短くする方針を書きました
  - 確認に使うコマンドも書いてあります
- **スモークテストを、まとまりごとに実行できるようにしました**（`-- --only=staff` など。カンマ区切りで複数指定できます）
  - まとまりは次のとおりです

    | まとまり | 内容 |
    |---|---|
    | `save` | セーブの移行 |
    | `rules` | お金・仕入れ・仕込み・評判とランク・日付・設備などのルール |
    | `layout` | 客席の並び |
    | `staff` | トッピングとホールスタッフ（`topping`）、出勤・在籍日数・研修（`shift`）、厨房（`kitchen`）。この3つは1つずつでも指定できます |
    | `days` | 画面で2日分まわす |

  - どのまとまりでも、最後に「本物のセーブは変わっていない」を確かめます
  - まとまりごとにかかった時間を `[smoke] time …` と出します
- **`--fixed-fps 60` を付けて実行するようにしました**
  - 実時間を待たずにフレームを進めます
  - ゲーム内の時間の進み方（1フレーム = 1/60秒 × 早送りの倍率）は同じなので、テストの中身と合格基準は変えていません
  - 付け忘れたときは「ヒント」を出します
- **スクリーンショットに `--shots=prep3,business` を足しました**
  - 選んだ場面を撮り終えたら、そこで終わります

## 自分で決めた仕様
- まとまりの名前（save・rules・layout・staff・days）は、今あるテストの関数の分け方に合わせました
  - 指示の例の「準備・営業」は、どちらも画面で2日分まわす部分（`days`）に入っています
  - 「お金」は `rules` に入っています
- 知らないまとまりの名前を指定したときは、エラーを出したうえで全部を実行します
